# Security

The extension requests `debugger` to send browser input to its chess.com tab and `storage` to retain preferences. Host access is limited to chess.com. Analysis runs locally; no analysis API, account credentials, or telemetry service is configured.

The extension does not include a stealth or detection-bypass mechanism. Browser policies, developer tools, or another debugger can prevent browser control. Do not try to work around administrator restrictions to run it.

When reporting a vulnerability, share a minimal reproduction without credentials or personal account data. If the repository owner has enabled GitHub private vulnerability reporting, use the repository's Security tab rather than posting sensitive details in a public issue. No security contact address is preconfigured in this upload package.
